# What the conversion changes

Every substitution below lives in code, so the tables here are copied from it. If you change a table, change the
code (the file is named in each heading) and re-run; `summary.txt` marks an id `*` ("explained") when it appears in
`BlockBackport.java` or the item log.

Source: Fabric 1.21.11 with community mods. Target: NeoForge 1.21.1 with Vanilla Backport (a mod that re-adds many
post-1.21.1 vanilla blocks, items and mobs to 1.21.1) and the official Create, Create Aeronautics and Offroad.

All code is in `chunker/cli/src/main/java/com/hivemc/chunker/conversion/encoding/java/backport/`.

## Blocks (`BlockBackport.java`)

Order of decision for every block written:

1. the substitution table below, if the id is in it;
2. a post-1.21.1 vanilla block that **Vanilla Backport registers** (list: `resources/backport/vb-blocks.txt`, generated by
   `scripts/gen_vb_blocks.py`) is written unchanged;
3. any other post-1.21.1 vanilla block goes to the fallback table, or is **dropped to air** (counted in the report as
   `block dropped (new vanilla, no equivalent)`).

| source block | becomes | states |
|---|---|---|
| `minecraft:iron_chain` | `minecraft:chain` | kept |
| `biomesoplenty:red_maple_leaf_litter` | `biomesoplenty:red_maple_leaf_pile` | dropped (the pile is one stateless block) |
| `biomesoplenty:orange_maple_leaf_litter` | `biomesoplenty:orange_maple_leaf_pile` | dropped |
| `biomesoplenty:yellow_maple_leaf_litter` | `biomesoplenty:yellow_maple_leaf_pile` | dropped |
| `biomesoplenty:purple_wildflowers` | `biomesoplenty:violet` | dropped |
| `biomesoplenty:marigold` | `biomesoplenty:orange_cosmos` | dropped |
| `biomesoplenty:flower_stem`, `flower_bud` | air | |
| `biomesoplenty:origin_oak_leaves` | `minecraft:oak_leaves` | kept |
| `biomesoplenty:origin_oak_log` | `minecraft:oak_log` | kept |
| `biomesoplenty:origin_rose` | `minecraft:poppy` | dropped |
| `biomesoplenty:origin_dandelion` | `minecraft:dandelion` | dropped |
| `universal_graves:grave` | `minecraft:chest` | `facing` from the grave rotation, `type=single`, `waterlogged` kept |
| `minecraft:copper_chest` and the `exposed_`, `weathered_`, `oxidized_`, `waxed_`, `waxed_exposed_`, `waxed_weathered_`, `waxed_oxidized_` variants | `minecraft:chest` | dropped; the block entity (and its items) is kept as a plain chest |

BOP giant flower petal blocks (`biomesoplenty:<colour>_flower_petal_block`) become a single flower of the same colour.
Only single-block flowers are used (a double flower would break):

| colour | becomes |
|---|---|
| red | `biomesoplenty:rose` |
| orange | `biomesoplenty:orange_cosmos` |
| yellow | `minecraft:dandelion` |
| pink | `biomesoplenty:pink_hibiscus` |
| purple | `biomesoplenty:violet` |
| magenta | `minecraft:allium` |
| blue | `minecraft:cornflower` |
| light_blue, cyan | `minecraft:blue_orchid` |
| white | `minecraft:oxeye_daisy` |
| light_gray | `minecraft:azure_bluet` |
| green, lime, brown, gray, black | air |

### Universal Graves (`GraveMapping.java`)

Universal Graves has no NeoForge 1.21.1 build. Each grave block is replaced by a chest holding the grave's items, read
from `data/universal-graves.dat`. A chest holds 27 stacks; the rest goes to a second chest on a free adjacent block
(up to 54 stacks in total, anything beyond is lost and counted as `grave items lost (more than 54)`). Stored
experience is lost (`grave experience lost` in the report). The `universal_graves:grave_compass` item becomes a normal
compass. For future deaths the pack uses the Gravestone mod instead.

## Biomes (`BlockBackport.remapBiome`)

| source biome | becomes |
|---|---|
| `biomesoplenty:subtropics` | `biomesoplenty:tropics` |
| `biomesoplenty:end_flats` | `minecraft:the_end` |

`minecraft:pale_garden` is kept (Vanilla Backport provides it).

## Items (`ItemSubstitutions.java`, `BopItemMap.java`)

Applied to every item stack anywhere: inventories, chests and other containers, backpack contents, ender chests, item
frames, item entities, player data, graves. Components belonging to the replaced mod are removed from the new item, and
`minecraft:damage` is clamped below the vanilla item's durability.

| source item | becomes |
|---|---|
| `minecraft:iron_chain` | `minecraft:chain` |
| `universal_graves:grave_compass` | `minecraft:compass` |
| any copper chest (`copper_chest`, `exposed_`, `weathered_`, `oxidized_`, `waxed_` variants) | `minecraft:chest` |
| BOP `<red\|orange\|yellow>_maple_leaf_litter` | `<colour>_maple_leaf_pile` |
| BOP `purple_wildflowers` | `biomesoplenty:violet` |
| BOP `marigold` | `biomesoplenty:orange_cosmos` |
| BOP `origin_oak_leaves`, `origin_oak_log`, `origin_rose`, `origin_dandelion` | `minecraft:oak_leaves`, `oak_log`, `poppy`, `dandelion` |
| BOP `<colour>_flower_petal_block` | same flower table as for blocks above; green, lime, brown, gray, black are removed |
| BOP `flower_stem`, `flower_bud` | removed |

### Expanded Weaponry (no NeoForge 1.21.1 build) becomes vanilla items

| source | becomes |
|---|---|
| `expanded_weaponry:heavy_<tier>_<helmet\|chestplate\|leggings\|boots>` | `minecraft:<tier>_<piece>` |
| `longbow`, `shortbow`, `slingshot` | `minecraft:bow` |
| `heavy_crossbow`, `arbalest` | `minecraft:crossbow` |
| `<tier>_spear` | `minecraft:<tier>_spear` |
| `<tier>_pickaxe`, `_axe`, `_shovel`, `_hoe` | `minecraft:<tier>_<tool>` |
| any other `<tier>_<weapon>` (dagger, hammer, greatsword, katana, twin blade, ...) | `minecraft:<tier>_sword` |

`<tier>` is one of wooden, stone, copper, iron, golden, diamond, netherite; an Expanded Weaponry id with another tier is
left as it was.

### Item components (`ItemDowngrade.java`, `backport-settings.json`)

1.21.1 stores items differently from 1.21.11. Items are rewritten into 1.21.1 form: only the components listed in
`target_components` of `backport-settings.json` (the vanilla 1.21.1 components) are kept, plus mod components handled
by `ModCompat.java`; anything else is dropped and counted (`component dropped`). Stock Chunker drops about half of the
newer components, including everything inside a Traveler's Backpack, which is why this repo carries its own item
downgrade.

## Entities (`EntityDowngrade.java`)

| change | detail |
|---|---|
| boats | one boat entity per wood type (1.21.2+) back to `minecraft:boat` / `minecraft:chest_boat` (or `biomesoplenty:boat` / `chest_boat`) with `Type` set to the wood (`oak`, `birch`, `maple`, `fir`, `umbran`, ...). Bamboo rafts likewise |
| wolf variants | a wolf variant that 1.21.1 + Vanilla Backport does not have is reset to `minecraft:pale`. Kept: ashen, black, chestnut, pale, rusty, snowy, spotted, striped, woods. (BOP's `spectral` wolves become pale) |
| cow, pig, chicken variants | anything other than `temperate`, `cold`, `warm` (for example `biomesoplenty:origin`) is reset to `minecraft:temperate` |
| attributes | `minecraft:max_health` back to `minecraft:generic.max_health` and so on (all vanilla attributes, `player.*`, `zombie.spawn_reinforcements`); `minecraft:waypoint_transmit_range` does not exist in 1.21.1 and is removed |
| equipment | `equipment` compound back to `HandItems` / `ArmorItems` / `body_armor_item` / `SaddleItem`, drop chances back to the old arrays |
| leash, home / travel positions, sleeping position, text components | converted to the 1.21.1 forms |
| removed fields | fields 1.21.1 never reads (`last_hurt_by_mob`, `sound_variant`, `anger_end_time`, ...); angry mobs simply calm down |
| passed through unchanged | `happy_ghast`, `nautilus`, `zombie_nautilus`, `copper_golem`, `camel_husk`, `parched` (Vanilla Backport mobs) and all the per-wood boat ids listed in `backport-settings.json` |
| player data | equipment moves back into inventory slots 100-103 and offhand; Balm player data moves to NeoForge persisted data |

Trial spawners get their configs inlined (1.21.1 stores the whole config; the vanilla ones are bundled, 15,516 in the
10-25 world). Block entities are downgraded the same way as entities (lock as plain string, furnace timers, text, item
components).

## Mod data formats (`ModCompat.java`, `ModWorldData.java`, `PlayerDataConverter.java`)

| mod | change |
|---|---|
| Create | `create:fluid_max_capacity` removed; Fabric fluid stacks `{fluidVariant, amount: long}` to NeoForge `{id, amount: int}`; `create:in_tag` values lose the `#` prefix; `create:bracketed_kinetic` block entity becomes `create:simple_kinetic`; track connections converted (bezier couples wrapped); components Create 6.0.10 does not have are dropped (for example `create:sequenced_assembly_progress`); `data/create_tracks.dat` (train graphs, signals, stations, trains and their carriage contraptions) converted |
| Waystones | `waystone_attunement` / `waystone_identity` components renamed to `attunement` / `waystone` and hold only the id; `data/waystones.dat` text names to JSON, enums upper case; name generator file renamed; per player data moved from `BalmData` to `NeoForgeData.PlayerPersisted` |
| Traveler's Backpack | `starter_upgrades` format changed; each `backpacks/<uuid>/*.dat` backup (read by `/tb restore`) is downgraded, which recovers the contents of dropped backpacks |
| Sable, Aeronautics, Simulated | **not converted**, see [KNOWN-GAPS.md](KNOWN-GAPS.md) |

## Mods that changed or were dropped

The pack changes from Fabric mods to the NeoForge builds of the same mods (the full list with versions and hashes is
[`mods/mods.lock.json`](../mods/mods.lock.json)). Notable replacements:

| Fabric 1.21.11 pack | NeoForge 1.21.1 pack |
|---|---|
| community ports of Create (create-fly), Create Simulated, Create Aeronautics, Offroad, Sable | official Create 6.0.10, `create-aeronautics-bundled` (Aeronautics + Simulated + Offroad), Sable 2.0.6 |
| Fabric API, Fabric Language Kotlin | not needed, Kotlin for Forge |
| Farmer's Delight Refabricated, connectiblechains, c2me-fabric, repurposed-structures-fabric | Farmer's Delight, Reconnectible Chains, C2ME NeoForge, Repurposed Structures (NeoForge) |
| Universal Graves | none for existing graves (they became chests); the Gravestone mod for new deaths |
| Expanded Weaponry | none; existing items became vanilla tools and weapons (table above) |
| Saturated Eating, Extended Vanilla Endgame | dropped, no NeoForge 1.21.1 build |
| VoxelMap | Xaero's Minimap and World Map |
| vanilla 1.21.2-1.21.11 additions | Vanilla Backport (blocks and mobs it covers), nearest equivalents elsewhere |

Added in the NeoForge pack: Chunky, ModernFix, Alternate Current, Almanac, Let Me Despawn, Structure Layout Optimizer,
Creating Space, Creeper Overhaul, Illager Invasion, YUNG's structure mods, When Dungeons Arise, MSS, ChoiceTheorem's
Overhauled Village. Simple Voice Chat is **not** included.
